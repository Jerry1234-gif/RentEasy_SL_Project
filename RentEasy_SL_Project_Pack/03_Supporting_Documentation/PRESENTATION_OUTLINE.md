# Presentation Outline — RentEasy SL

1. Title and team introduction.
2. Background and validated problem (use genuine research findings only).
3. Aim, objectives and scope.
4. Stakeholders and user roles.
5. Existing process and proposed solution.
6. Use case and DFD diagrams.
7. System architecture and database ERD.
8. UI mockups and design decisions.
9. Live demonstration: tenant search → landlord listing → admin moderation → tenant viewing/application → manager decision.
10. Testing approach and actual results.
11. Limitations, privacy safeguards and future enhancements.
12. Reflection, conclusion and questions.

## Demo sequence
Prepare seeded synthetic accounts. Start with public search; sign in as landlord and submit a listing; sign in as admin and publish it; sign in as tenant and favourite/request viewing/apply; return as landlord to decide requests. Do not use real personal data. Have screenshots and database backup available in case the live environment fails.
